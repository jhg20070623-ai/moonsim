# Logistics batching comparison

This model applies three MoonSim batch policies to the same 17 arrival times:

    0, 1, 2, 3, 4, 12, 13, 14, 15, 16, 24, 25, 26, 27, 28, 35, 36

Each released batch has a two-tick delivery delay. FixedTime uses a five-tick wait interval, FixedBatch releases at three items, and Hybrid uses a three-item threshold or five-tick maximum wait. FixedBatch cannot release a partial batch on its own, so the model force-releases any remaining items at end of intake, five ticks after the final arrival. An entity is counted as overdue if it waits more than five ticks before batch release.

Run from the repository root:

    moon run examples/logistics_batching
