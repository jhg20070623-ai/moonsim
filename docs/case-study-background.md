# Historical manufacturing case-study background

The project owner supplied the following figures from an earlier manufacturing material-flow project. They are preserved as historical background only. They were not calculated by MoonSim and do not represent output from the current engine or the manufacturing_line example.

| Measure | Historical before | Historical after |
|---|---:|---:|
| Work centers | 7 | 4 shared work centers |
| Material travel distance | 196 m per item | 59 m per item |
| Line balance rate | 48.21% | 84.38% |

The current manufacturing_line example is a separate model with seven stations, 20 entities, six-tick arrival spacing, and processing times of 12/8/6/10/5/4/9 ticks. Its README reports values produced by running that model. The two datasets should not be compared as if they shared the same layout, assumptions, units, or calculation method.
